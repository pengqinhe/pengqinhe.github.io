# Demo sources

These silent, web-sized H.264 copies are excerpts from the associated project demonstrations. No playback speed changes were applied.

- `pi-imle.mp4`: PI-IMLE reactive manipulation, from https://kianhk6.github.io/IMLE-VLA/static/videos/real/reactive_ours_success.mp4
- `scene-graph-real.mp4`: Franka feed-animals task, from https://pengqinhe.github.io/Scene-Graph-CVPR2026-website/assets/videos/real-feed-animals.mp4
- `scene-graph-sim.mp4`: simulated Spot heat-up-tea task, from https://pengqinhe.github.io/Scene-Graph-CVPR2026-website/assets/videos/sim-heat-tea.mp4

The matching JPEG posters were extracted at two seconds. Videos load only when requested through native playback controls. Project links next to each demo point to the complete research context.
